# assets/music/

Background music. **Not playable**: SDL_mixer was removed in #9 and the engine has no MP3
decoder. Music is generated by code instead (the M5 sequencer, #49). The file is kept with the
other 2D assets.

| File | Format |
|------|--------|
| `time_for_adventure.mp3` | MP3, 320 kbps, 44.1 kHz, joint stereo (~1.6 MB) |
